# 🎋 태화강 십리대숲 3D 힐링 가상 산책 공간

울산 태화강 십리대숲을 모티브로 제작된 웹 기반 **3D 인터랙티브 힐링 산책 웹 애플리케이션**입니다.  
귀여운 3등신 캐릭터를 조작하여 바람에 살랑이는 대나무 숲길과 반짝이는 태화강변을 거닐고, 벤치에 앉아 바람소리와 새소리에 귀를 기울이며 명상할 수 있습니다.

---

## 🌿 주요 특징 및 업그레이드 기능

1. **3등신 캐릭터 & 통과 방지 충돌 시스템**:
   - 밀짚모자와 배낭을 멘 귀여운 3등신 캐릭터와 아장아장 걷는 절차적 모션.
   - **대나무 통과 방지 슬라이딩 충돌 처리**: 대나무를 뚫고 지나갈 수 없도록 물리 충돌 처리 적용.
   - **최소 1.9m 간격 보장**: 캐릭터 지름(약 0.7m)의 2.7배 이상으로 대나무 사이 간격을 균일하게 확보하여 이동 중 끼임 현상 완벽 방지.

2. **다채로운 산책로 네트워크 & 태화강변 인도**:
   - **태화강변 보행 인도 (Promenade)**: 강변을 따라 시원하게 뻗은 보행 데크와 안전 나무 난간 및 감성 가로등 설치.
   - **숲속 오솔길 (Inner Bamboo Trail)**: 대나무 숲 깊은 곳을 관통하며 힐링할 수 있는 황토 흙길.
   - **태화강 연결 샛길 (River Connector)**: 숲속 오솔길에서 태화강변 보행 인도로 바로 이어지는 횡단로.

3. **벤치 인터랙션 & 힐링 모드**:
   - 강변 쉼터 벤치 근처에서 `[E]` 키로 앉기.
   - **🍃 바람소리 감상하기**: 대나무 숲의 흔들림이 커지고 잎새 서걱거림과 바람소리가 풍성해짐.
   - **👁️ 눈감기 (명상 모드)**: 화면이 서서히 암전되며 호흡 가이드 서클(들이쉬기-멈춤-내쉬기) 애니메이션 제공, 입체 자연 앰비언스에 몰입.

4. **Web Audio API 절차적 자연 사운드**:
   - 대나무 잎 마찰음, 청아한 산새 지저귐, 태화강 흐르는 소리, 부드러운 바람소리 실시간 합성.

## 🎮 조작 방법

| 키 / 마우스 | 기능 |
| :--- | :--- |
| `W`, `A`, `S`, `D` / 방향키 | 산책로, 숲속 오솔길, 강변 인도 거닐기 |
| `마우스 좌클릭 드래그` | 3인칭 시점 360도 둘러보기 |
| `마우스 휠` | 카메라 줌 인 / 줌 아웃 |
| `E` 키 | 벤치 앉기 / 일어나기 |
| `ESC` 키 | 눈감기(명상 모드)에서 눈뜨기 |

## 🌐 GitHub 올려서 웹에서 바로 실행하기 (GitHub Pages)

본 프로젝트는 설치나 빌드 과정 없이 정적 웹 호스팅(GitHub Pages)에서 100% 즉시 동작합니다.

### 1단계: GitHub에 새 저장소(Repository) 만들기
1. [GitHub](https://github.com/new)에 접속하여 새 리포지토리를 생성합니다 (예: `tae-hwa-bamboo-forest`).
2. Public(공개)으로 설정합니다.

### 2단계: 프로젝트 터미널에서 푸시하기
프로젝트 폴더(`virtual`)에서 아래 명령어를 순서대로 실행합니다:
```bash
git remote add origin https://github.com/<본인-깃허브-아이디>/<저장소-이름>.git
git branch -M main
git push -u origin main
```

### 3단계: GitHub Pages 켜기
1. 저장소의 **Settings** -> **Pages** 메뉴로 이동합니다.
2. **Build and deployment** 항목의 **Source**를 `GitHub Actions`로 선택합니다.
3. 약 1분 뒤 상단에 표시되는 **`https://<아이디>.github.io/<저장소-이름>/`** 링크를 클릭하면 전 세계 어디서든 웹 브라우저에서 바로 실행할 수 있습니다!
